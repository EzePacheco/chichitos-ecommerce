# Chichitos Store — UI Kit

Recreación visual completa del ecommerce de Chichitos. Mobile-first, responsive, con flow click-thru.

## Pantallas

1. **Home** — hero, destacados, bloque DTF, cómo comprar
2. **Catálogo** — grid + filtros
3. **Producto** — galería, selectores (talle/color/diseño), personalización
4. **Carrito** — items, subtotal, envío
5. **Checkout** — datos, entrega (cálculo por distancia), Mercado Pago
6. **Admin** — dashboard simple para la dueña

## Cómo correrlo

Abrí `index.html`. La navegación es client-side (hash routing). Los datos son mocks en `data.js`.

## Componentes

Ver `components.jsx`. Cubre: `Header`, `Footer`, `Logo`, `Button`, `GarmentTag`, `ProductCard`, `GarmentPlaceholder`, `WhatsAppFloat`, `Section`, `Eyebrow`, `Icon`, `Chip`, `Stepper`, `EmptyState`, `OrderStatusBadge`.
